# Viewer

The picture and PDF viewer of Love Suite: pictures open fitted to the window, the arrows go
through the folder in Explorer's order, zoom, full screen, Trash (Explorer's Undo puts it back), Open in
Preview for the rest.

Install: `brew install --cask love-suite/tap/viewer` (once the first release is out).

Development: `swift build`, `swift test`, `scripts/make-app.sh` (Swift 6.4.2, macOS 13 or later).
